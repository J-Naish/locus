# Workspace Fixtures

Sample folder trees for workspace loading, file scanning, search, and cache tests.

## Fixture Sets

- `basic/`: representative document workspace with folders and common files.
- `sorting/`: numeric, case, and folder-before-file ordering examples.
- `os-noise/`: entries that should be ignored by default.
- `dotfiles/`: hidden project files that should remain visible.
- `unicode/`: non-ASCII, spaces, symbols, and long names.
- `file-types/`: one file per supported extension family.
- `symlinks/`: links that should be listed without following traversal.
- `permissions/`: read-only and permission-oriented examples.
