# Markdown Video Fixtures

These short clips are derived from MDN's `cc0-videos/flower` sample:

- Source MP4: `https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4`
- Source WebM: `https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.webm`

The `.mov`, `.m4v`, and HLS `.m3u8` variants are local test derivatives of the
same CC0 sample, generated with `ffmpeg` so the Markdown renderer can exercise
multiple video container/playlist extensions without depending on network
access.
