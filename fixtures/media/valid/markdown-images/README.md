# Markdown Image Fixtures

These images are fixture assets for exercising Markdown image rendering. They
are intentionally varied by aspect ratio and file format: JPEG, PNG, WebP, GIF,
TIFF, BMP, JPEG 2000, and SVG.

Most assets are synthetic and do not depend on external copyrighted source
images. The following real-world samples are downloaded from Wikimedia Commons
`Special:FilePath` thumbnails and kept small for fixture use:

- `earthrise-nasa.jpg`: NASA Apollo 8 Earthrise image.
  Source: <https://commons.wikimedia.org/wiki/Special:FilePath/NASA-Apollo8-Dec24-Earthrise.jpg?width=1200>
- `blue-marble-nasa.png`: NASA Blue Marble 2002 image.
  Source: <https://commons.wikimedia.org/wiki/Special:FilePath/Blue%20Marble%202002.png?width=1200>
- `starry-night-public-domain.jpg`: public-domain scan of Van Gogh's
  *The Starry Night*.
  Source: <https://commons.wikimedia.org/wiki/Special:FilePath/Van%20Gogh%20-%20Starry%20Night%20-%20Google%20Art%20Project.jpg?width=1200>
